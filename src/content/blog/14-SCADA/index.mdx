DP-01 全流程
## 1-业务描述
   双属性求平均值（DP-01）
   - **功能描述**：双属性求平均值。
   - **输入与对象**：me 为设备；读 A、B，写 Avg。
   - **接口使用**：`TryGetProVal<double>` 两次、`SetProVal<double>` 一次。
   - **边界要求**：任一读取失败不计算不写入；计算前过滤非有限值；结果超量程不写入。
   - **设计约束**：不报警、不延时；属性名以常量给出；日志仅记录失败点。
## 2-构建真 API 代码
根据描述、编写规范、API 文档，构建真 API CPP 函数体代码 `001_DP_DualPropAverage.cpp`
```cpp
{
constexpr const char *kPropA = "A";
constexpr const char *kPropB = "B";
constexpr const char *kPropAvg = "Avg";
constexpr double kDoubleMax = std::numeric_limits<double>::max();
// 若项目定义了 Avg 的工程量程，将这两个常量替换为其上下限。
constexpr double kAvgMin = -kDoubleMax;
constexpr double kAvgMax = kDoubleMax;
static_assert(kAvgMin >= -kDoubleMax && kAvgMax <= kDoubleMax &&
kAvgMin <= kAvgMax, "Invalid Avg range");
if (!ctx) {
return;
}
if (!me) {
ctx->Log("求平均值失败：当前设备为空");
return;
}
double a = 0.0;
if (!me->TryGetProVal<double>(kPropA, a)) {
ctx->Log("设备 {} 读取 {} 失败", me->GetId(), kPropA);
return;
}
double b = 0.0;
if (!me->TryGetProVal<double>(kPropB, b)) {
ctx->Log("设备 {} 读取 {} 失败", me->GetId(), kPropB);
return;
}
if (!std::isfinite(a) || !std::isfinite(b)) {
ctx->Log("设备 {} 输入非有限：A={}，B={}", me->GetId(), a, b);
return;
}
constexpr double kHalfMax = kDoubleMax / 2.0;
// 幅值过大时先折半，避免计算中间和时溢出。
const double avg = (std::abs(a) > kHalfMax || std::abs(b) > kHalfMax)
? a / 2.0 + b / 2.0
: (a + b) / 2.0;
if (!std::isfinite(avg) || avg < kAvgMin || avg > kAvgMax) {
ctx->Log("设备 {} 平均值无效或超量程：Avg={}", me->GetId(), avg);
return;
}
if (!me->SetProVal<double>(kPropAvg, avg)) {
ctx->Log("设备 {} 写入 {} 失败，写入值={}", me->GetId(), kPropAvg, avg);
return;
}
}
```
